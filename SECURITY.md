# Security

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/schreibtischhelden/markdown-pages.js/security/advisories/new)
instead of opening a public issue.

## Threat model

markdown-pages.js is a client-side renderer. Everything it shows comes from
Markdown files on the same origin, which are written by the site owners.
The relevant attack surface is therefore:

1. **The URL** (`?page=...`, `#hash`) – fully controlled by anyone who sends a link.
2. **Markdown content** – trusted authors, but a mistake or a compromised
   contributor must not turn into script execution.
3. **Third-party code** – the libraries that convert, sanitize and style the content.

## Protections

| Area | Measure |
| :--- | :--- |
| Page selection | The query string is mapped to a relative path that may only contain `A-Z a-z 0-9 _ - .` per segment (no leading dot, no `..`, no `//`, no `:`). Anything else shows "Page not found". Before fetching, the resolved URL must have the same origin as the site. |
| HTML output | The HTML generated by Showdown is sanitized with [DOMPurify](https://github.com/cure53/DOMPurify) before it is inserted into the page (`<script>`, `<style>`, `<iframe>`, event handlers, `javascript:` URLs etc. are removed). Links with `target` get `rel="noopener noreferrer"`. |
| Content Security Policy | `index.html` sets a CSP via `<meta>`: scripts, styles, fonts and fetches only from the same origin, no plugins, `base-uri` and `form-action` restricted. No inline event handlers are used. |
| Third-party code | All libraries are stored in `assets/vendor/` (no CDN at runtime), pinned in `package.json`, updated via Dependabot. GitHub Actions are pinned to commit SHAs. CodeQL runs on every PR. |

## Recommendations for deployments

- Serve the site over HTTPS.
- If your host allows response headers, additionally send the CSP as an HTTP header
  and add `frame-ancestors 'self'`, `X-Content-Type-Options: nosniff` and
  `Referrer-Policy: strict-origin-when-cross-origin` (these cannot be set via `<meta>`).
- If you need HTML that the sanitizer removes (e.g. `<iframe>` embeds), extend
  `MarkdownPages.sanitizeConfig` in your own script and the CSP `frame-src` deliberately,
  e.g. `MarkdownPages.sanitizeConfig.ADD_TAGS = ['iframe'];` – only for trusted sources.
